# Phase 5: Physics-Informed Kinematic Drift Model

## 1. Objective
To predict future iceberg positions using purely physical environmental forcing (ocean currents, wind) without relying on unverified training datasets.

## 2. Methodology
The system utilizes a deterministic kinematic approach:
1. **Environmental Sampling:** Extracts current `uo`, `vo` (ocean) and `wind_u`, `wind_v` (atmosphere) at the iceberg's initial coordinate.
2. **Iceberg Velocity Calculation:**
   `ice_u = (alpha * ocean_u) + (beta * wind_u)`
   `ice_v = (alpha * ocean_v) + (beta * wind_v)`
3. **Displacement Conversion:**
   `speed = sqrt(ice_u^2 + ice_v^2)`
   Mathematical Angle (CCW from East): `atan2(ice_v, ice_u)`
   Navigation Bearing (CW from North): converted internally.
4. **Geographic Propagation:**
   Applies spherical trigonometry (Haversine-based destination propagation) to map speed (m/s) into displacement (km) over forecast horizons (`6h, 12h, 24h, 48h, 72h`).

## 3. Physical Assumptions & Configurable Parameters
- **Ocean Coupling (`alpha = 1.0`):** Configurable model parameter / initial assumption. NOT a measured physical constant. Allows calibration via historical trajectories.
- **Wind Coupling (`beta = 0.02`):** Configurable model parameter / initial assumption. NOT a measured physical constant. Allows calibration via historical trajectories.
- **Coriolis/Deflection:** The CMEMS ocean-current product is generated by an ocean modelling system whose underlying dynamics account for relevant ocean physics. The present iceberg trajectory model does not explicitly solve the iceberg force balance or Coriolis equation.
- **Constant Forcing:** Assumes sampled environmental forcing remains constant for the forecast horizon.

## 4. Limitations
This is a physics-informed kinematic drift model, NOT a fully coupled physical iceberg dynamics model. Known limitations include:
- Depth-varying currents are not explicitly resolved (relies on surface/near-surface inputs).
- Wave forcing is excluded.
- Windage uncertainty (variability in drag coefficients).
- Iceberg geometry (draft and sail area are not uniquely modelled).
- Keel interaction with bathymetry is excluded.
- Calving/fracture events are not predicted.
- Sub-grid eddies are unresolved.
- Environmental forecast uncertainty is not dynamically propagated.

## 5. Uncertainty
Uncertainty is generated via a `1 km + 5% displacement` growth envelope. This is explicitly labeled a **"heuristic/modelled uncertainty envelope"** and should NOT be interpreted as a statistically calibrated confidence interval.
